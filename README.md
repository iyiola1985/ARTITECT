# SholaTech demo · Artitec

A cinematic demonstration site for Artitec, a fictional house of designer residences. SholaTech is the agency behind the demo. It is not part of the Artitec mark.

## Run locally

From this folder:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Production check:

```bash
npm run build
npm start
```

The enquiry form validates in the browser and then shows a summary. It does not send anything.
